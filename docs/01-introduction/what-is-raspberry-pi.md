# 01. 라즈베리파이란?

## 소개

라즈베리파이(Raspberry Pi)는 영국의 라즈베리파이 재단에서 개발한 **초소형 싱글보드 컴퓨터(SBC, Single Board Computer)**입니다. 신용카드 크기의 작은 보드에 컴퓨터의 모든 기능이 들어있어, 저렴한 가격으로 컴퓨팅을 배우고 다양한 프로젝트를 만들 수 있습니다.

## 탄생 배경

라즈베리파이는 2012년 처음 출시되었으며, 다음과 같은 목표로 개발되었습니다:

- **교육 목적**: 학생들에게 저렴한 가격으로 프로그래밍과 컴퓨터 과학을 가르치기 위해
- **접근성**: 누구나 쉽게 구입하고 사용할 수 있는 컴퓨터
- **실험과 창의성**: 하드웨어와 소프트웨어를 결합한 다양한 프로젝트 개발

## 주요 특징

### 1. 저렴한 가격
- 기본 모델 기준 약 $35~$75 (모델에 따라 다름)
- 교육 및 취미 프로젝트에 부담 없는 가격

### 2. 작은 크기
- 신용카드 크기 (85.60mm × 56.5mm)
- 휴대성이 뛰어나고 설치 공간 최소화

### 3. 완전한 컴퓨터
- CPU, GPU, RAM, USB 포트, HDMI 출력 등 모두 포함
- 일반 PC처럼 모니터, 키보드, 마우스를 연결하여 사용 가능

### 4. GPIO 핀
- **GPIO (General Purpose Input/Output)** 핀을 통해 전자 부품 제어
- LED, 센서, 모터 등 다양한 하드웨어 연결 가능
- 물리적 컴퓨팅과 IoT 프로젝트에 최적

### 5. 다양한 운영체제 지원
- Raspberry Pi OS (기본, Debian 기반)
- Ubuntu, Ubuntu Core
- Windows 10 IoT Core
- RetroPie (게임 에뮬레이션)
- 기타 리눅스 배포판

### 6. 활발한 커뮤니티
- 전 세계적으로 수백만 명의 사용자
- 풍부한 튜토리얼과 프로젝트 예제
- 활발한 포럼과 커뮤니티 지원

## 라즈베리파이 모델 비교

### Raspberry Pi Zero / Zero W / Zero 2 W
| 특징 | 설명 |
|------|------|
| **크기** | 매우 작음 (65mm × 30mm) |
| **가격** | $5~$15 |
| **성능** | 기본적인 작업에 적합 |
| **용도** | 초소형 프로젝트, 웨어러블, 임베디드 시스템 |
| **특징** | Zero W는 Wi-Fi/Bluetooth 내장, Zero 2 W는 쿼드코어 CPU |

### Raspberry Pi 4 Model B
| 특징 | 설명 |
|------|------|
| **CPU** | 쿼드코어 Cortex-A72 (1.5GHz) |
| **RAM** | 2GB / 4GB / 8GB 옵션 |
| **USB** | USB 3.0 × 2, USB 2.0 × 2 |
| **디스플레이** | 듀얼 4K HDMI 출력 |
| **네트워크** | 기가비트 이더넷, Wi-Fi 5, Bluetooth 5.0 |
| **용도** | 데스크톱 컴퓨터, 미디어 센터, 서버, 고성능 프로젝트 |

### Raspberry Pi 5
| 특징 | 설명 |
|------|------|
| **CPU** | 쿼드코어 Cortex-A76 (2.4GHz) |
| **RAM** | 4GB / 8GB 옵션 |
| **성능** | Pi 4 대비 2~3배 향상 |
| **특징** | PCIe 2.0 지원, 향상된 카메라/디스플레이 인터페이스 |
| **용도** | 최신/최고 성능이 필요한 모든 프로젝트 |

### Raspberry Pi 400
| 특징 | 설명 |
|------|------|
| **형태** | 키보드 일체형 |
| **사양** | Raspberry Pi 4와 동일 |
| **용도** | 데스크톱 컴퓨터, 교육용 |

## 라즈베리파이로 할 수 있는 것들

### 1. 학습 및 교육
- 프로그래밍 배우기 (Python, JavaScript, C++ 등)
- 리눅스 운영체제 학습
- 전자공학 및 하드웨어 제어 학습
- 컴퓨터 과학 기초 개념 이해

### 2. 홈 서버
- NAS (Network Attached Storage)
- 웹 서버
- 파일 서버
- VPN 서버
- DNS 서버 (Pi-hole)

### 3. 미디어 센터
- Kodi, Plex를 이용한 홈 시어터
- 음악 스트리밍 서버
- 디지털 사진 액자

### 4. IoT 및 홈 자동화
- 스마트홈 컨트롤러
- 온습도 모니터링
- 보안 카메라
- 자동 식물 관리 시스템
- 날씨 관측소

### 5. 레트로 게임기
- RetroPie를 이용한 고전 게임 에뮬레이션
- 아케이드 머신 제작

### 6. 로봇 및 하드웨어 프로젝트
- 자율주행 로봇
- 드론 제어
- 3D 프린터 컨트롤러
- CNC 기계 제어

### 7. 인공지능 및 머신러닝
- TensorFlow Lite를 이용한 이미지 인식
- 음성 인식 비서
- 객체 감지 시스템

### 8. 개발 및 테스트
- 웹 개발 테스트 환경
- CI/CD 파이프라인
- 네트워크 테스트 장비

## 장점

✅ **저렴한 가격**: 부담 없이 시작 가능
✅ **작은 크기**: 공간 절약, 휴대성
✅ **낮은 전력 소비**: 24시간 가동해도 전기료 부담 적음
✅ **확장성**: GPIO를 통한 무한한 확장 가능성
✅ **풍부한 자료**: 튜토리얼, 프로젝트, 커뮤니티 지원
✅ **다양한 OS**: 목적에 맞는 운영체제 선택 가능
✅ **교육적 가치**: 프로그래밍과 하드웨어를 동시에 학습

## 단점

❌ **제한된 성능**: 고사양 게임이나 영상 편집 등 무거운 작업에는 부적합
❌ **저장공간**: 별도의 SD 카드 필요, 내장 스토리지 없음
❌ **주변기기 별도 구매**: 케이스, 전원 어댑터 등 추가 구매 필요
❌ **기술적 진입장벽**: 리눅스와 하드웨어에 대한 기본 지식 필요

## 누가 사용하면 좋을까?

- 🎓 **학생**: 프로그래밍과 컴퓨터 과학을 배우고 싶은 학생
- 👨‍💻 **개발자**: IoT, 임베디드 시스템 개발자
- 🔧 **메이커**: DIY 프로젝트를 즐기는 메이커
- 🏠 **홈랩 운영자**: 홈 서버나 자동화에 관심 있는 사람
- 🎮 **레트로 게임 팬**: 고전 게임을 즐기고 싶은 사람
- 📚 **교육자**: 학생들에게 기술을 가르치는 선생님
