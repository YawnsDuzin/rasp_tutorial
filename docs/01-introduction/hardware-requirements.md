# 02. 필요한 하드웨어

라즈베리파이를 시작하기 위해 필요한 하드웨어를 알아봅니다. 필수 구성품과 선택 구성품으로 나누어 설명합니다.

## 필수 구성품

### 1. 라즈베리파이 보드

가장 먼저 라즈베리파이 보드를 선택해야 합니다.

**추천 모델 (2024년 기준)**:
- **입문자**: Raspberry Pi 4 Model B (4GB RAM)
- **고성능**: Raspberry Pi 5 (8GB RAM)
- **휴대용/소형**: Raspberry Pi Zero 2 W
- **데스크톱**: Raspberry Pi 400 (키보드 일체형)

**선택 기준**:
- 예산: Zero ($15) ~ Pi 5 ($80)
- 용도: 학습용 vs 서버용 vs 휴대용
- 성능: 간단한 프로젝트 vs 고사양 작업

### 2. 전원 어댑터

라즈베리파이에 전력을 공급하는 전원 어댑터가 필요합니다.

| 모델 | 전원 규격 | 커넥터 |
|------|-----------|--------|
| **Pi Zero/Zero W/Zero 2 W** | 5V 2.5A | Micro USB |
| **Pi 3 Model B/B+** | 5V 2.5A | Micro USB |
| **Pi 4 Model B** | 5V 3A | USB-C |
| **Pi 5** | 5V 5A | USB-C (27W 권장) |
| **Pi 400** | 5V 3A | USB-C |

⚠️ **주의사항**:
- 공식 전원 어댑터 사용 권장
- 부족한 전력 공급 시 불안정하거나 부팅 실패 가능
- 스마트폰 충전기는 전력이 부족할 수 있음

### 3. MicroSD 카드

라즈베리파이의 운영체제와 저장공간으로 사용됩니다.

**권장 사양**:
- **용량**: 최소 16GB, 권장 32GB 이상
- **속도**: Class 10 이상, UHS-I 권장
- **브랜드**: SanDisk, Samsung 등 신뢰성 있는 제품

**용량별 용도**:
- 16GB: 기본 OS 설치 및 간단한 프로젝트
- 32GB: 일반적인 사용 (권장)
- 64GB+: 미디어 센터, 많은 데이터 저장

💡 **팁**: A2 등급 카드는 더 빠른 성능을 제공합니다.

### 4. MicroSD 카드 리더기

PC에서 SD 카드에 OS를 설치하기 위해 필요합니다.

- USB MicroSD 카드 리더기
- 노트북에 내장된 SD 카드 슬롯 사용 가능 (어댑터 필요)

### 5. 모니터 및 케이블

라즈베리파이 화면을 보기 위한 디스플레이입니다.

**연결 방법**:
- **Pi 4/5**: Micro HDMI to HDMI 케이블 (2개 포트, 듀얼 모니터 지원)
- **Pi 3 이하**: HDMI to HDMI 케이블
- **Pi Zero**: Mini HDMI to HDMI 어댑터/케이블

**대안**:
- SSH로 헤드리스(모니터 없이) 설정 가능
- VNC를 통한 원격 데스크톱 사용

### 6. USB 키보드 및 마우스

초기 설정 시 필요합니다.

- 일반 USB 키보드/마우스
- 무선 키보드/마우스 (USB 동글)
- Bluetooth 키보드/마우스 (Pi 3 이상)

**대안**: SSH 원격 접속 시에는 불필요

## 선택 구성품

### 1. 케이스

라즈베리파이 보드를 보호하고 미관을 좋게 합니다.

**종류**:
- **기본 케이스**: 플라스틱 케이스 ($5~10)
- **팬 포함 케이스**: 냉각 팬이 내장된 케이스 ($10~20)
- **공식 케이스**: 라즈베리파이 재단 공식 케이스
- **아크릴 케이스**: 내부가 보이는 투명 케이스
- **금속 케이스**: 방열 효과가 있는 알루미늄 케이스
- **레트로 케이스**: 고전 컴퓨터 디자인 케이스

💡 **팁**: Pi 4/5는 발열이 있어 팬 또는 히트싱크 포함 케이스 권장

### 2. 히트싱크 및 쿨링 팬

과열을 방지하고 성능을 유지합니다.

**필요성**:
- Pi Zero/3: 일반 사용 시 불필요
- Pi 4/5: 권장 (고부하 작업 시 필수)

**종류**:
- 히트싱크: CPU/RAM 칩에 부착하는 알루미늄 방열판
- 쿨링 팬: 5V 소형 팬 (30mm, 40mm)
- 공식 Active Cooler: Pi 5용 공식 쿨러

### 3. 카메라 모듈

사진/비디오 촬영, 컴퓨터 비전 프로젝트에 사용합니다.

**종류**:
- **Camera Module 3**: 12MP, 최신 모델
- **Camera Module 2**: 8MP, 가성비
- **HQ Camera**: 12.3MP, 렌즈 교환 가능, 고화질
- **NoIR Camera**: 적외선 카메라, 야간 촬영

**용도**: 보안 카메라, 타임랩스, 객체 인식 등

### 4. 센서 및 전자 부품

GPIO를 통해 다양한 하드웨어 프로젝트를 만들 수 있습니다.

**입문자 키트 추천**:
- 브레드보드
- 점퍼 와이어
- LED (다양한 색상)
- 저항 (220Ω, 10kΩ 등)
- 푸시 버튼
- DHT11/DHT22 온습도 센서
- PIR 모션 센서
- 초음파 거리 센서 (HC-SR04)

**스타터 키트**:
- Sunfounder, Freenove, CanaKit 등의 브랜드에서 판매
- 센서, 부품, 튜토리얼이 포함된 올인원 키트

### 5. 네트워크 케이블

안정적인 네트워크 연결을 위한 이더넷 케이블입니다.

- Cat5e/Cat6 이더넷 케이블
- Wi-Fi가 없거나 불안정한 환경에서 유용
- 서버 용도로 사용 시 유선 연결 권장

### 6. USB 허브

USB 포트가 부족할 때 사용합니다.

- Powered USB Hub (전원 공급형) 권장
- USB 3.0 지원 허브 (Pi 4/5)

### 7. 외장 저장장치

대용량 저장공간이 필요한 경우 사용합니다.

**종류**:
- USB 플래시 드라이브
- 외장 HDD/SSD
- USB 3.0 지원 (Pi 4/5에서 빠른 속도)

**용도**: NAS, 미디어 서버, 백업

### 8. 디스플레이 모듈

독립적인 소형 디스플레이가 필요한 프로젝트에 사용합니다.

**종류**:
- 3.5" / 5" / 7" 터치스크린 LCD
- OLED 디스플레이 (0.96", 1.3")
- E-Paper 디스플레이

**용도**: 스마트 미러, 날씨 표시, 시계 등

### 9. 배터리 (휴대용)

전원이 없는 곳에서 사용할 때 필요합니다.

- USB 파워뱅크 (10,000mAh 이상 권장)
- UPS HAT (무정전 전원 공급)

### 10. HAT (Hardware Attached on Top)

GPIO 위에 장착하는 확장 보드입니다.

**인기 HAT**:
- **Sense HAT**: 센서 모음 (온도, 습도, 압력, 자이로, 가속도계)
- **PoE HAT**: Power over Ethernet (이더넷으로 전원 공급)
- **Pimoroni**: 디스플레이, 오디오 HAT 등
- **Waveshare**: 다양한 센서 및 디스플레이 HAT

## 구매 가이드

### 추천 구매 조합

**📦 입문자 패키지 ($80~100)**:
- Raspberry Pi 4 (4GB)
- 공식 전원 어댑터
- 32GB MicroSD 카드 (OS 사전 설치)
- HDMI 케이블
- 케이스 (팬 포함)
- USB 키보드/마우스

**📦 올인원 스타터 키트 ($100~150)**:
- 위의 모든 구성품
- 센서 및 전자부품 키트
- 튜토리얼 북

**📦 서버/헤드리스 패키지 ($60~80)**:
- Raspberry Pi 4 (2GB 이상)
- 공식 전원 어댑터
- 32GB MicroSD 카드
- 케이스
- 이더넷 케이블
(모니터, 키보드 불필요 - SSH 사용)

### 구매처

**국내**:
- 엘레파츠
- 디바이스마트
- 아이씨뱅큐
- 쿠팡, G마켓, 네이버 쇼핑

**해외**:
- 공식 판매처: raspberrypi.com
- Adafruit, SparkFun, Pimoroni
- Amazon, AliExpress

💡 **팁**:
- 공식 판매처에서 구매하면 정품 보장
- 스타터 키트는 개별 구매보다 저렴
- 배송비와 관세 고려

## 예산별 추천

| 예산 | 구성 | 용도 |
|------|------|------|
| **$50 이하** | Pi Zero 2 W + 필수품 | 학습, 간단한 프로젝트 |
| **$80~100** | Pi 4 (4GB) + 필수품 | 일반적인 사용, 학습 |
| **$120~150** | Pi 4 (4GB) + 필수품 + 센서 키트 | 하드웨어 프로젝트 |
| **$150~200** | Pi 5 (8GB) + 필수품 + 주변기기 | 고성능 프로젝트, 서버 |
